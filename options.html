Appearance

Inbox pages

GitHub paginates the notification inbox before views filter it, so a focused view can leave one page nearly empty. Extra pages are read from GitHub’s own inbox pages with your existing session.

Collapsible items

Related notifications, pull requests, and issues can share one expandable row.

Backup and sync

Chrome sync stores these settings in your Chrome profile when browser sync is enabled. JSON backup includes every preference, global view, rule, and repository override; temporary GitHub caches are excluded.
